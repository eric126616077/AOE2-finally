# 帝國鍛造坊：Roblox RTS 測試版

受《帝國時代 II》啟發的 Roblox RTS，使用 Luau 與 Rojo 7.6.1。包含城堡廣場集合、可設定的對局、AI 經濟與軍隊、四個時代、村民施工、交貨、科技與勝負規則，新增桌面／觸控操作與新手練習；仍是需要 Roblox Studio 驗收與持續完善的測試版，不是 100% 複製或完整《帝國時代 II》。玩家介面與提示使用繁體中文。

## 開始對局

進入 Play 後先以 Roblox 角色出現在城堡廣場。走到城堡前的光圈進入等待傳送門；走近時也可按 E 或「加入等待傳送門」。加入必須實際靠近傳送門，第一位集合的玩家成為房主。

房主設定要等齊的 1–4 名真人玩家，以及地圖、電腦、難度、人口、資源和勝利規則。設定由伺服器驗證並同步給所有人；修改配置、有人加入或退出集合，都會取消所有人的準備。必須等齊指定人數，並由每位玩家確認配置、按「準備完成」，房主才能按「開始戰局」。電腦不取代尚未到齊的真人名額；真人與 AI 合計最多四方。

開局在同一個伺服器內移除大廳角色、切換到 RTS 地圖與俯視相機，目前沒有跨 place 傳送。每方從一座已完成的市鎮中心、三名村民與一名斥候騎兵開始。開局後加入的玩家觀戰，下一局再參加。

| 設定 | 選項與規則 |
| --- | --- |
| 集合人數 | 1–4 名真人玩家，必須等齊指定人數且全部準備。 |
| 地圖 | 小型 768、標準 1024、大型 1536 studs；預設標準。格線為 8 studs。 |
| 電腦 | 0–3 方，與設定的真人人數合計最多四方；0 AI 且只有一名玩家時為沙盒練習。 |
| AI 難度 | 簡單、普通、困難；影響經濟規模、軍隊規模與進攻頻率。 |
| 每方人口上限 | 60、100、150、200；仍須建造房屋取得實際人口容量。 |
| 初始資源 | 標準：食物 300、木材 300、黃金 150、石材 150。豐富：食物／木材各 1200、黃金 800、石材 600。 |
| 勝利規則 | 征服、主城決戰、奇觀。 |

每局由伺服器產生新地圖種子，四個出生區的樹林、金礦、石礦與漿果群各自隨機選擇位置、方向和不規則形狀。每方開局皆有兩片密集樹林（48／40 棵）、8 叢漿果、9 座金礦與 7 座石礦，位於基地 128–260 studs 範圍；外圍資源位置不同但各區種類與總量相當。小型／標準／大型提供 760／1280／2200 個節點，森林由中心密集成長，中立樹林通常為 36–72 棵。群內間隔縮至約 13 studs，樹冠加寬相接，碰撞占地維持 8 studs；群與群之間保留空隙，基地周圍保留 128 studs 建設區，大道和中央戰場保持淨空。`Workspace.MapSeed` 可供重現測試；在伺服器呼叫 `WorldGenerator.Generate(sizeName, makeResource, seed)` 可指定種子。完整複製使用 `Workspace.StreamingEnabled=false`，RTS 不依賴玩家角色作為串流中心。

## 經濟、建造與發展

村民採集後先攜帶資源，交到自己的合適建築才加入餘額。市鎮中心、城堡與市集可收四種資源；磨坊收食物，伐木場收木材，採礦營地收黃金與石材。農田可提供食物，採集點耗盡後需要尋找其他資源；農田耗盡保留建築。經濟科技會增加採集效率、攜帶量或農田容量。

自動工作（預設開啟，可在戰局選單切換）：閒置約 2 秒的村民會先協助 64 studs 內的己方工地，再交回攜帶的資源，最後依目前分工缺口採集 80 studs 內的資源；完工的村民立刻接續附近工地，伐木場／採礦營地／磨坊完工後優先採集它收取的資源；耗盡的農田在木材足夠時自動重新播種並照常扣款。玩家右鍵地面移動或按停止的村民保持待命，直到再收到工作指令。新訓練、沒有集合點的村民也會自動找工作。全部由伺服器決定，AI 經濟仍照原規則。

未選取任何目標時，底部面板直接顯示建築分類；放置後伺服器派最近的村民施工（2×2 一人、3×3 兩人、更大三人），優先閒置村民，不會拉走正在施工的村民。選取自己的存活村民後，則只由所選村民施工。混選軍隊時，客戶端只指派其中的己方村民施工；只有軍隊、敵方村民或沒有選中村民時不能建造。伺服器仍拒絕含軍隊或非己方村民的原始建造請求且不扣款。建築必須在地圖內、占地無障礙、達到所需時代且資源足夠；指定村民可從遠處走到工地，沒有 80 studs 建造距離限制。

村民實際到達工地才增加施工進度。停止、改派工作或離開工地會停工，已完成的進度保留；再右鍵工地可繼續施工，也可選更多村民協作。軍隊不能協助施工，AI 也必須派自己的村民施工。完工後才啟用房屋人口、建築訓練／研究／交貨／防禦功能及農田食物。右鍵自己的受損建築可修復，修復消耗木材。

人口由已完成建築提供，房屋增加 5 人口；每棟生產建築可排五個單位，佇列預留人口。出口被堵住時等待空位，不強行把單位生進障礙。

共 18 種建築：市鎮中心、房屋、磨坊、伐木場、採礦營地、兵營、農田、射箭場、馬廄、兵工廠、市集、瞭望塔、石牆、城堡、攻城器械廠、修道院、大學、世界奇觀。修道院在城堡時代訓練僧侶，並研究狂熱、神聖。增建市鎮中心需城堡時代；城堡需 650 石材。

| 升級 | 成本 | 前置條件 |
| --- | --- | --- |
| 黑暗 → 封建 | 500 食物 | 完成兩種不同的黑暗時代經濟／軍事建築，例如兵營、磨坊、伐木場、採礦營地。 |
| 封建 → 城堡 | 800 食物、200 黃金 | 完成兩種不同的封建時代經濟／軍事建築，例如射箭場、馬廄、兵工廠、市集。 |
| 城堡 → 帝王 | 1000 食物、800 黃金 | 完成一座城堡，或兩種不同的城堡時代建築，例如攻城器械廠、修道院、大學。 |

房屋、農田、城牆、瞭望塔與市鎮中心不列入上述兩種建築計數。同一種建築蓋兩座仍只算一種。選自己的市鎮中心後按「升級時代」或 U；生產與研究共用建築，需要先清空其佇列。

共 21 項科技：織布機、手推車、手拉車、雙刃斧、弓鋸、金礦開採、石礦開採、馬軛、重犁、鍛造、鎖甲、鱗甲馬鎧、箭羽、錐頭箭、拇指環、血統、侍從、狂熱、神聖、化學、徵兵制度。科技在對應建築研究，需符合時代與資源條件；重犁需先研究馬軛，手拉車需手推車，弓鋸需雙刃斧，錐頭箭需箭羽。織布機改善村民生命與護甲，手推車提升村民效率，軍事科技改變適用部隊的攻擊、護甲、射程與攻擊間隔。

市集可每次買入或賣出 100 食物、木材或石材：買入花 130 黃金，賣出獲得 70 黃金。目前採固定交換價格。

## 軍隊與勝利

共 11 種單位：村民、步兵、長槍兵、弓箭手、斥候騎兵、矛兵、騎士、僧侶、攻城衝車、投石車、巨型投石機。兵營、射箭場、馬廄、修道院、攻城器械廠與城堡負責各類生產，後期單位依時代解鎖。

僧侶（100 黃金，城堡時代）不會攻擊也不反擊。右鍵敵方單位招降：在 36 studs 射程內至少 4 秒，之後每秒 28% 機率成功，10 秒必定成功；成功後單位轉為己方並保留生命比例，僧侶信仰歸零，25 秒恢復後才能再次招降。建築與敵方僧侶不能招降。右鍵自己或同盟的受傷單位治療（每秒 2 生命，攻城器械除外）；待命僧侶會自動治療附近的受傷己方單位。陣營軍事升級（鍛造、鎖甲、箭羽、化學）不影響僧侶。規則在 `ServerModules/MonkRules.lua`，`tests/monk.spec.lua` 為純邏輯檢查；招降與治療尚未在 Studio Play 實機驗收。

軍隊會自動索敵與反擊；瞭望塔及城堡會自動射擊。長槍兵克制騎兵，矛兵克制弓箭手，騎士適合突襲遠程部隊，攻城衝車與巨型投石機有對建築加成；投石車可造成範圍傷害。傷害、護甲、資源、所有權與移動由伺服器決定，客戶端的步行、採集、攻擊與介面動畫只負責顯示。

部隊可選方陣、橫列、縱隊、楔形與散開五種陣形。選取自己的軍隊後可直接點陣形卡片；村民或混合部隊可按 F 或「陣形」開啟陣形頁，按 B／建造分類回到建築操作。點選會取代目前工作，讓所選單位在附近重新列隊；後續右鍵地面、右鍵小地圖與觸控移動沿用陣形。介面以金框及「使用中」標記伺服器確認的陣形，手機可橫向捲動卡片。

伺服器依目的地方向旋轉陣形、按最大單位碰撞半徑留間距，並將整組目的地平移到地圖內；大型橫列／縱隊必要時分成多列。個別單位仍沿用尋路與避讓，繞過障礙時不保證全程維持剛性陣形，戰鬥仍使用原有索敵行為。混選不同陣形的部隊會顯示「混合陣形」，下一次地面移動以首選單位的陣形重新列隊；Ctrl + 1–9 保留原有選取編隊功能。明確呼叫的引擎驗證與雙人步驟見 [陣形驗證](tests/FORMATIONS-STUDIO.md)。

- **征服**：摧毀對方全部單位與建築才消滅該陣營，包括房屋、農田及城牆；最後存活的陣營獲勝。
- **主城決戰**：保護開局那座市鎮中心。起始主城被摧毀立即戰敗，後來增建的市鎮中心不替代勝敗目標。
- **奇觀**：完工的世界奇觀須存活 180 秒才獲勝；消滅所有其他陣營也可獲勝。
- 玩家投降或離開會清除其單位與建築。沒有對手的征服／主城決戰沙盒不自動宣布勝利；投降後可回大廳。單人奇觀局仍可達成奇觀勝利。
- 對局結束可觀戰結果，由房主返回大廳調整設定並重開，無須重新啟動 Play。

## 操作

城堡廣場使用一般 Roblox 角色移動與相機。以下操作適用於開局後的 RTS：

| 操作 | 功能 |
| --- | --- |
| WASD／方向鍵、Shift | 移動相機；Shift 加速。 |
| 滾輪、Home、左鍵小地圖 | 縮放、回基地、移動視角。 |
| 左鍵、左鍵拖曳 | 選取、框選自己的單位。 |
| Shift + 左鍵、雙擊單位 | 加選／取消單選、選取畫面內同類型單位。 |
| 右鍵地面／資源／敵人 | 移動／採集／攻擊。 |
| 選取單位後右鍵小地圖 | 所選己方單位移動到對應位置，保留目前視角；多選編隊會留在地圖邊界內。 |
| 村民右鍵自己的建築 | 協助施工、修復，或交回攜帶的資源。 |
| B、R | 切換建造頁、研究頁；建築用介面卡片選擇。 |
| F、陣形按鈕／卡片 | 開啟陣形頁；選擇方陣、橫列、縱隊、楔形或散開並重新列隊。 |
| 建築預覽時左鍵、Shift + 左鍵 | 指派已選村民建造一次、保留預覽以連續放置；改變選取會取消預覽。未選村民時改派最近的村民。 |
| 選單「自動工作」 | 開關閒置村民自動施工、交貨、採集與農田重新播種。 |
| 右鍵／Esc | 取消建築預覽。 |
| T、U、X | 在選取建築訓練預設單位、升級時代、停止所選單位。 |
| V、H、句點 `.` | 選全部自己的村民、選市鎮中心、循環選取閒置村民。 |
| Ctrl + 1–9、1–9、快速連按同一數字 | 儲存編隊、選取編隊、把相機移到編隊。 |

右上「動態」可減少介面與單位的視覺動態；「選單」可開啟邊緣捲動。HUD 有資源、人口、時代、陣營資訊、選取單位資料、建造／訓練／研究、佇列、小地圖與戰局選單。輸入命中與相機座標考慮 GuiInset，HUD 使用 UIScale 適應視窗。

音效、音樂與游標回饋：音效改用 Roblox 授權素材庫（ProSoundEffects 音效、APM Music 配樂）並依實測響度平衡，選取不同單位／建築有各自的識別音，命令、採集、施工、戰鬥、陣亡、建築倒塌與受攻擊號角各有短音效；配樂分大廳、和平與持續交戰三組播放清單交叉淡入，時代升級與勝敗有過場音樂，對局中有鳥鳴風聲環境音。滑鼠依右鍵將執行的動作顯示伐木、採礦、採集、建造、修復、攻擊、集合點或不可用標記，並描邊游標下的目標；下令時地面出現光圈或目標閃爍。受攻擊時播放號角、顯示提示並在小地圖閃紅圈，按空白鍵前往。選單可切換音樂、調整音樂與音效音量。素材載入失敗時改用 Studio 內附替代音。所有效果都在客戶端，不決定資源或傷害；[音效與游標紀錄](docs/AUDIO-CURSOR-2026-10-02.md)與[先前回饋驗證](docs/FEEDBACK.md)記錄測試範圍。
