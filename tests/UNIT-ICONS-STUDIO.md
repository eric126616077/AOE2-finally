# 單位圖示與選取資訊驗證

目前十種單位共用 `Shared/UnitIcons.lua` 的原創幾何肖像，套用到訓練按鈕、訓練佇列、單選資訊與框選清單。

框選清單逐一顯示每個單位的圖示、生命值與血條；點選圖示改為單選，Shift / Ctrl 點選移出選取。大量選取可捲動，桌機使用格狀清單，觸控使用橫向清單。

單選資訊包含名稱、勢力、目前工作、陣形、生命值、攻擊、護甲、射程、移速、攻擊間隔、人口、攻擊加成、範圍傷害、訓練成本與基礎訓練時間。村民另顯示攜帶資源、容量與四種資源的採集速率；較長資訊保留在可捲動容器。

## 在 Studio 重現

1. 建置隔離快照：`./rojo.exe build unit-icons-validation.project.json -o build/AOE2-unit-icons-validation.rbxlx`。
2. 開啟快照並 Play。測試專用 LocalScript 會透過正常大廳指令開始無 AI 的新自由建設局，再執行 `Shared.UnitIconTests.Run()`。
3. 桌機、手機橫向與手機直向分別在新 Play 執行。`UnitIconTests` 只建立本機測試模型，並還原選取、Age、分頁；不發送遊戲指令。
4. 檢查 Output 的 `UNIT_ICON_TEST COMPLETE` 與 `UNIT_ICON_HARNESS COMPLETE`，並實際拖曳框選起始村民、點圖示查看詳細資訊。

测试覆盖十種圖示的辨識造型、逐單位生命更新、200 個圖示及末端捲動、訓練／佇列、完整資訊、安全區域與面板附近地面命中。harness 另確認真實伺服器同步射程、攻擊間隔、攜帶容量與四種採集速率。

測試快照不含未知使用者模型，也不自動同步或發布現有 place。手機模擬器檢查不代表真實手機的觸控實測；雙人同步與玩家離開清理需獨立驗證。
