# Roblox RTS 調查與產品假說

調查日期：2026-09-30（Asia/Taipei）。本檔案使用《Age of Empires II: Definitive Edition》官方教學、Roblox 官方檔案／報告及作品作者在 Roblox 的介紹。以下分清楚「來源事實」、「本專案選擇」和「尚待玩家驗證的假說」。沒有進行訪談、問卷或正式玩家實驗，不能把公開搜尋資料當作本作品的需求證明；也不能保證成為爆款。

## 1. 定位結論

Roblox 已有 RTS 與大型戰略作品。「平台沒有這種型別」不成立。適合驗證的定位是：**在 Roblox 上用容易學會的操作，建立中世紀聚落，帶朋友一起進行公平的即時戰略對局**。核心魅力應來自村民經濟、地圖控制、兵種互剋與可看懂的戰鬥；外觀和文明主題提供自我表達，不提供付費優勢。

這是根據下列來源提出的產品方向，尚不是市場結論。第一批測試須確認 Roblox 新手是否真的理解、願意完成一局且願意再玩，不能用功能數量替代這些結果。

## 6. 公平付費規範

使用者已明確要求：不能 Pay to Win，付費僅可買文明或造型。以下是本專案的規則，不是外部市場事實。

1. **第一版文明為主題選擇。** 所有文明共用同一份資源、人口、成本、採集、施工、訓練、移動、HP、傷害、護甲、射程、視野、科技與勝利條件；只改變建築／軍隊風格、旗幟、名稱和裝飾。免費文明同樣可贏得完整對局。
2. 若未來做不同策略文明，所有 PvP／排位參戰者必須能使用同一完整文明池，無付費或冗長遊玩門檻；付款可以買文明主題收藏、外觀或非競技展示資格。僅說「數值大致平衡」不足以保證購買多種反制選項沒有優勢。
3. 不售資源、人口、速度、生產佇列、復活、戰鬥強化、科技、永久戰力、視野、競技配對優先權或針對付費玩家的更弱 AI。不用廣告換取這些優勢。
4. 造型不得改變碰撞／佔地、選取難度、可見度、攻擊辨識、兵種辨識或隱藏重要畫面。付費建築與單位仍使用相同權威實例及數值。
5. 商店寫清楚商品、價格、擁有狀態與用途；購買／持有由 Roblox 伺服器 API 驗證，客戶端不能宣稱擁有。未知商品 ID 或未配置商店時顯示尚未開放，不能偽造付款。
