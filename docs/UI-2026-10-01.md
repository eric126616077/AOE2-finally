# 2026-10-01 介面改進與驗收記錄

本輪重設受《帝國時代 II》啟發的 RTS 介面，改善資源閱讀、選取後的情境指令、生產管理與手機操作。這是 Roblox RTS 測試版的階段成果，不是 100% AOE2 複製，也不是完整遊戲；原創介面與幾何美術不代表官方遊戲的美術、科技樹與全部玩法已實作。

## 本輪改進

| 區域 | 玩家可使用的內容 |
| --- | --- |
| 視覺與資源列 | 木色面板、黃銅色邊框與原創資源圖示；食物、木材、黃金、石材、人口及時代。桌面資源卡增加各資源採集人數，閒置村民按鈕顯示實際數量。 |
| 桌面情境指令 | 每頁十二格、兩列指令；選自己的村民才顯示建造，選生產建築顯示對應訓練／研究，選軍隊顯示可用指令，查看資源或其他陣營不提供己方操作。 |
| 選取資訊 | 模型預覽、名稱、生命值、攻擊／護甲／移速、攜帶資源；建築顯示完工或停工狀態、施工村民及進度。單位資料的畫面位置跟隨客戶端呈現。 |
| 生產佇列 | 逐格顯示已排入的單位，點選可取消頭項或等待項，退回伺服器當時扣除的全部訓練成本並釋放預留人口。按鈕送出顯示時的 `QueueRevision`，過時點擊不會取消其後的單位或多退資源。 |
| 集合點 | 選自己的已完工生產建築，可用右鍵或「集合點」按鈕設定地面／資源位置，並清除集合點。新村民可直接前往採集，新軍隊走到集合位置；本地旗幟不阻擋射線與碰撞。 |
| 戰術地圖 | 增加相機視野範圍，提供全部／經濟／軍事篩選；單位位置使用客戶端呈現位置。 |
| 刪除確認 | 刪除單位、拆除建築或取消工地前顯示確認面板；提醒不退款，並對主城決戰的起始主城提示戰敗後果。變更選取、對局或按 Esc 會取消確認快照。 |
| 手機介面 | 使用安全區域與 UIScale，主要觸控按鈕保留至少 44 × 44 像素；生產佇列移到可見指令區並可橫向捲動。短橫向畫面將指令區放右側、觸控操作列放左下，保留地面空間。 |
| 最後手機補丁 | 多選時顯示單位總數、村民／軍隊數及合計生命值；訓練／研究中的標題顯示建築名稱、項目、剩餘秒數與百分比，佇列頭項增加黃銅色進度條。 |

經濟、建造、訓練、退款、集合點指令與刪除仍由伺服器驗證與執行。UI 與客戶端的預覽、旗幟和動態不決定資源或傷害。生產規則與 API 詳見 [生產佇列與集合點](PRODUCTION-2026-10-01.md)。

## 效能證據的界限

[30 秒小地圖摘要](../tests/map-performance-small-30s-summary-20261001.json) 的實際採樣時間約 30.13 秒、4 個單位、有效平均約 59.9 FPS。`configuredFourBy200=false`、`observedFourBy200=false`，而且 focus 為 Unknown；這是少量單位的單人樣本，不能推論 800 單位或多人表現，也沒有對照基準可歸因某項改動的效能收益。

另一份 45 秒 JSON 輸出被截斷，不能作為完整效能證據。本輪不宣稱效能基準比較、大軍戰鬥、多人負載或長局穩定性已通過。

後續地圖 agent 已在同一 r2 驗證副本完成 Small／Medium／Large 的地圖檢查，以及 Small 中正常生產至 4／10／20 個單位後的 idle／move／stop 九個約 30 秒窗口。相同鏡頭與 viewport 下有效 FPS 約 49.95–50，焦點仍為 Unknown，沒有修改前 baseline，因此仍不判定效能 PASS。另核對了 20 單位停止、佇列清空與正常投降／返回大廳的清理；這不等於玩家離開或多人清理驗收。完整數據、原始 INCOMPLETE 與限制分別見 [地圖紀錄](MAP-PERFORMANCE-20261001.md) 與 [有限負載紀錄](PERFORMANCE-LOAD-20261001.md)。地圖 agent 已停止 Play 並釋放 Studio 操作權。
