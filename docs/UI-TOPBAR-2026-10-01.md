# 頂列與選取面板調整

本輪依照使用者截圖，把桌面資源列移到 Roblox 按鈕旁，移除底部中央的「選取情報」整塊面板。這是 RTS 原型的介面調整，不是完整 AOE2 一致性驗收。

## 介面

- `AOE2_TopbarGUI` 使用 Roblox `TopbarSafeInsets`，自動避開 CoreGui 按鈕；頂列隨視窗與 `TopbarInset` 變化重排。一般介面仍使用原本安全區與 UIScale。
- 頂列的命中檢查與一般介面共用 CoreUI 座標，只扣除一次 GuiInset。透明空間不攔截世界操作，停用頂列時也不攔截。
- `SelectionInfo` 與獨立肖像已移除。訓練佇列、集合點、刪除、施工狀態、生命值與簡短目標資料改放在 `CommandDock`。
- 村民建築頁保留十二格。其他桌面指令頁最多六格，讓第二列可以顯示佇列與狀態；手機保留原先的四格指令與觸控操作列。
- 從主城生產或科技頁選到村民，會自動切回建築頁，避免沿用主城分頁而顯示錯誤空白提示。
- 手機窄視窗仍使用原先安全區內的資源卡；本次同排調整針對截圖中的桌面 HUD。
- 大廳不顯示戰局頂列。一般介面上的選單與確認視窗層級高於頂列，頂列回呼沿用既有 modal 驗證。
