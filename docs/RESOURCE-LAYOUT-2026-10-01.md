# 隨機資源佈局

每局由伺服器產生新種子，各出生區獨立生長不規則森林、礦脈與漿果群。保留相當的資源配額，不再逐點四方鏡射。指定第三個參數 `WorldGenerator.Generate(sizeName, makeResource, seed)` 可重現同一地圖；實際種子公布於 `Workspace.MapSeed`。

每個出生區有 24／18 棵的兩片樹林、6 叢漿果、7 座金礦、5 座石礦，距基地 128–230 studs。中立資源依共同配額、各區獨立位置生成，林群 12–30 棵、礦石／漿果通常 4–8 個；空間不足時拆成較小連接群。小型／標準／大型維持 420／680／1100 個節點。群間距 20、群內格距 16 並有細微偏移；基地 128、中央 64 studs 與道路淨空不變。群落角度限制在直角附近 ±10°，避免軸對齊占地膨脹後封住村民通道。

生成器先完成位置規劃才建立模型。僅清除標記 `RTSManagedResource` 的舊資源，保留未知模型與外觀模板；工廠失敗不公布完整節點數。草地裝飾也讀取實際種子，同尺寸新局會重新生成。
