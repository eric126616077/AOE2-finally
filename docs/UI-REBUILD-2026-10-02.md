# 2026-10-02 介面重造：鐵與金主題、資源列

本輪重新設計 HUD 外觀與資源列。這是 RTS 原型的介面階段成果，不是完整遊戲。資源、扣款與人口仍由伺服器決定，客戶端只顯示。

## 變更

| 區域 | 內容 |
| --- | --- |
| 整體主題 | 深鐵灰面板、漸層金邊框、上緣受光線與下緣暗縫；按鈕改為冷色鐵灰，選取／主要按鈕帶金色調。大廳、覆盤、刪除確認、選單同樣套用。全螢幕遮罩不畫邊框。 |
| 標題緞帶 | 領地與戰局、對戰勢力、戰術地圖、戰局選單改用深色緞帶＋金菱形標題；指令面板頂列加深色標頭帶。 |
| 資源列 | 每格：圓形徽章圖示、角落採集村民數、資源名稱、近 60 秒入帳（`+N/分`）與庫存數值。數值增加閃綠、減少閃紅，並浮出差額；「減少動態」開啟時不播放。 |
| 人口 | 底部進度條顯示人口／上限；接近上限顯示「將滿」，額滿時數值、邊框與進度條轉紅並顯示「已滿」。 |
| 時代 | 羅馬數字菱形徽章（I–IV）、時代名稱、對局時間；升級中顯示倒數與進度條，進度以 `Config.Ages[下一時代].time` 計算。寬度足夠時置於頂列剩餘空間中央。 |
| 閒置村民 | 村民頭像＋數量徽章；有閒置時按鈕轉為金色主要狀態，沒有時頭像灰階。 |
| 選單 | 頂列只保留一個「☰ 選單」按鈕；原「動態」快捷鍵移除，設定仍在選單內的「動態：一般／減少」。 |
| 對戰勢力 | 每列左側顯示勢力顏色條，戰敗時變淡。 |

收入為客戶端由正向庫存變化推估，包含市場交易與退款；換局或離開對局時重設。

## 保留的介面契約

`AOE2_TopbarGUI`（TopbarSafeInsets）、`EmpireBar`、`Resource_<key>`、`IdleVillagerButton` 的 `IdleCount`、資源卡 `Gatherers` 屬性、`CommandDock`、`MinimapPanel`、`GameMenu` 及其六個按鈕名稱、命中區域與 GuiInset 計算方式均未改變。資源卡仍加入命中清單，手機版資源列搬到 HUD 時同樣不穿透。
