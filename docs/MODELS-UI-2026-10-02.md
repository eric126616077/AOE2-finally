# 模型與介面全面重做（2026-10-02）

原型美術與介面改進，不代表完整遊戲。修改前備份：`backups/20261002-models-ui/`。美術規範見 [ART-STYLE.md](ART-STYLE.md)。

## 模型

所有替代模型仍由 Roblox 基本零件組成（沒有網格、貼圖或外部資產），但全部重新設計，並拆成模組：

| 檔案 | 內容 |
| --- | --- |
| `Shared/ArtKit.lua` | 共用色盤與基本形狀（暖色童話色盤；屋頂分紅陶瓦／茅草／石板三個家族） |
| `Shared/ArtBuildingsA.lua` | 市鎮中心、房屋、兵營、射箭場、馬廄、兵工廠、市集、攻城器械廠、大學 |
| `Shared/ArtBuildingsB.lua` | 修道院、磨坊、伐木場、採礦營地、瞭望塔、石牆、城堡、世界奇觀、農田 |
| `Shared/ArtUnits.lua` | 11 種單位、村民五種工具、四種背負物 |
| `Shared/ArtNature.lua` | 樹、金礦、石礦、漿果叢（各三個耗損階段） |
| `Shared/Art.lua` | 公開 API，不變：`Create / SetTool / SetCarry / ResourceStage / ApplyPlayerColor / AddPlayerMarker` |

- **玩家色改為點綴**：屋頂面不再整片染成玩家色，改由屋脊、旗幟、盾牌、遮陽篷、風車帆等辨識。
- **比例貼合占地**：每棟建築照「占地 × 高度」設計，不再被等比例縮小而顯得又小又空。
- **資源耗損階段**：剩餘量 ≤ 2/3、≤ 1/3 時換外觀；農田逐列收割，耗盡未重播時休耕。只替換程式產生的替代外觀，Studio 匯入的模板不受影響（也就沒有階段變化）。
- **村民**：伐木斧、採礦鎬、農田鋤、漿果籃、施工／修復鎚；背上顯示攜帶的木材、食物、黃金、石材。
- **朝向**：採集、施工、修復、攻擊、招降、治療到位後，伺服器把單位轉向目標（只轉向、不改位置）。
- **場景**：日照調亮、縮短陰影、提高飽和度；草地、道路、水面改為與新色盤同調的顏色。

## 介面

- **主題**：整套改為「羊皮紙＋木框」淺色主題，面板、按鈕、標題緞帶、大廳、覆盤、選單與選取面板使用同一套元件與顏色（先前是深色鐵灰面板配羊皮紙選取面板兩套並存）。
- **資源圖示**：指令卡價格為「圖示＋數字」，哪一種資源不足只標紅那一項；點選樹／礦／漿果時，選取面板顯示該節點目前階段的立體肖像、資源圖示與存量條。
- **版面**：對戰勢力面板高度隨勢力數量伸縮並貼齊小地圖；手機版的時代標籤加上底色；大廳入口卡的強調色加深以利閱讀。
- **修正**：沒有選取任何東西時，選取面板不再空白顯示。
- **版面重排（桌面）**：對局資訊（「領地與戰局」與「對戰勢力」）移到右上角並依勢力數量伸縮；新手指引移到左上角；底部指令面板、選取面板、小地圖等高並對齊成一排控制台（小地圖面板 230×220、地圖 184）；快捷鍵提示加上底條。沒有選取時，指令面板與小地圖之間仍保留可點擊的戰場（`HUDTests` 的既有要求）。手機版版面未改。
- **圖示（全部重畫）**：
  - 資源：木材（端面朝外的原木堆）、食物（綁起的三穗麥束）、黃金（錢幣堆）、石材（砌好的石塊）、人口（兩位村民）。
  - 數值：攻擊（交叉雙劍）、護甲（胸甲）、射程（拉開的弓）、移速（奔跑的靴子）、攻擊間隔（碼錶）；空手改為空籃子。
  - 指令與科技：斧、鎬、鎚、手推車、愛心、燒瓶、卷軸、停止、旗幟；每項科技依效果使用對應圖示（`GUIManager` 的 `techIcons`）。
  - 單位肖像：11 種全部重畫成與新模型一致的造型，外框加上所屬玩家色的色環。`UnitIconTests` 的辨識造型名稱（`PickShaft`、`SwordBlade`、`LongSpear`、`Bowstring`、`Javelin`、`HorseHead`、`HorseFaceplate`、`RamLog`、`ThrowingArm`、`Counterweight`）都保留。
