## 目標

以《帝國時代 II》的操作回饋為參考，取代先前六個 Studio 內附音檔（跳躍、腳步、滑桿）的測試版提示音：

- 選取時依單位／建築播放識別音，下令有確認音，經濟與戰鬥有可分辨的世界音效。
- 有背景配樂、交戰配樂、過場音樂與環境音。
- 滑鼠預告右鍵會做什麼，下令時畫面有回應，受攻擊時有警報。

所有內容只在客戶端，不影響資源、扣款、傷害或任何伺服器判定。

## 素材來源與授權

全部使用 Roblox Creator Store 上由 Roblox 授權、可在任何 Roblox 體驗中使用的素材：

- 音效：ProSoundEffects（帳號 `ProSoundEffects`）與少量 Roblox 官方帳號素材（投石車發射）。
- 配樂與過場：APM Music（帳號 `APMOfficial`）。

這些素材的授權僅限在 Roblox 平台內使用，不可匯出到其他平台。素材編號、起始時間（TimePosition）與音量都在 `src/ReplicatedStorage/Shared/FeedbackRules.lua`。

素材挑選與平衡方式：以 Creator Store 搜尋 API 篩選授權帳號，下載後用 ffmpeg 解碼，量測每段的起音時間、峰值與 50 ms 短時響度，裁出主要擊打點並換算音量，讓不同素材的響度相近。配樂依整首 RMS 響度換算音量，因此切換曲目時音量一致。這只是量測平衡，**實際聽感仍需人耳調整**。

若某個素材在玩家端無法載入（離線 Studio、素材下架或被審核），播放器會改用 `fallback` 所列的 Studio 內附音，而不是靜音。

- 大廳：〈Royal Court〉等宮廷曲。
- 對局（和平）：〈Saltarello (Italy ca.1400)〉、〈Pavane For Crumhorn And Drum〉、〈Galliard For A Queen〉、〈Court Minstrel〉等 11 首中世紀／文藝復興曲隨機播放，不連續重複同一首。

- 對局中播放鳥鳴與林間風聲環境音（跟隨音效音量與音效開關）。

### 游標

- 平時為箭頭；游標下有可選取的物件時改為指向手勢並描邊（自己白、敵方紅、盟友青、資源金）。
- 選取村民時，滑到樹木、金礦、石礦、漿果／農田分別顯示斧頭、十字鎬、麥穗標記；滑到自己未完工的建築顯示鐵鎚，受損建築顯示工具。
- 選取任何部隊時，滑到敵方單位或建築顯示交叉雙劍；軍隊滑到資源只視為移動。
- 放置建築時顯示鐵鎚或禁止標記（與放置驗證一致）；設定集合點時顯示旗幟，不可用目標顯示禁止標記。
- 游標在 HUD 上時一律為一般箭頭。
- 系統游標始終保持顯示，動作標記是跟隨滑鼠的小圓章。即使腳本出錯，游標也不會消失。觸控模式不顯示。
